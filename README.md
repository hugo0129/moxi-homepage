# 莫西 MOXI · 把 AI 带进真实世界

莫西的个人网站，记录 AI 应用、知识分享与江西 AI 圈的实践。

纯 HTML、CSS、JavaScript，使用真实活动照片，支持桌面与移动端。无需构建，无第三方脚本和追踪器。

## 内容

- 关于莫西：研发、技术管理与 AI 实践经历。
- 正在做的事：AI 应用、企业培训、知识分享与社区共建。
- 实践方法：梳理问题、小范围试用、经验沉淀。
- 江西 AI 圈：活动现场与注明时点的社区数据。
- 实战笔记：四篇公开文章，支持按主题筛选。
- 保持连接：现有公开交流表单与社群入口。

## 本地预览

```sh
python3 -m http.server 4318 --bind 127.0.0.1 --directory docs
```

打开 http://127.0.0.1:4318 。也可以直接打开 `docs/index.html`。

## GitHub Pages

网站地址：https://hugo0129.github.io/moxi-homepage/

Pages 使用 `main` 分支的 `/docs` 目录。推送该目录的更新后，GitHub 自动重新发布。

## 编辑

- `docs/index.html`：页面内容、文章与联系链接。
- `docs/style.css`：响应式布局和黑白红视觉风格。
- `docs/script.js`：手机菜单与文章分类筛选。
- `docs/assets/`：照片、头像与图标。
- `SOURCES.md`：公开来源与素材说明。

联系按钮会打开外部网站；本站没有表单接收后端。人物照片、文章与品牌素材的权利归各自权利人所有。
